# 多用户自动部署方案（自动分配端口）

收到，完全没问题！为了让操作更“傻瓜化”，我将原来的手动指定端口改为**自动分配并记录**。

## 1. 新的实施方案

### 核心改进：自动端口账本
脚本会自动维护一个“小账本”（文件），记录谁用了哪个端口。
- **新用户**：脚本会自动查找当前最大的端口号，往后顺延分配（比如上一个人用了 10000，新用户就自动分 10002）。
- **老用户**：如果再次运行脚本（比如重启），脚本会查账本，继续使用原来分配给他的端口，不会乱变。

### 使用流程
您只需要输入同事的名字（拼音）：
```bash
bash scripts/deploy-user.sh zhangsan
```
脚本会输出：
> ✅ 已为 zhangsan 分配端口：UI(10000), API(10001)
> 🚀 服务启动成功！访问地址：http://服务器IP:10000

---

## 2. 详细技术实现

我将创建 `scripts/deploy-user.sh`，包含以下智能逻辑：

1.  **账本管理**：
    - 在 `users/ports.map` 文件中记录 `用户名=起始端口`。
    - 默认起始端口从 `10000` 开始（避开常用端口），每人占用 2 个端口（一个网页，一个后端接口）。

2.  **自动配置与隔离**：
    - **目录隔离**：自动创建 `users/zhangsan/notebook_data` 等目录。
    - **配置生成**：自动生成 `docker-compose.zhangsan.yml`，填入自动分配的端口。
    - **网络隔离**：为每个用户创建独立的 Docker 网络（可选，或加前缀区分），防止容器名冲突。

3.  **状态管理命令**：
    - `bash scripts/deploy-user.sh list`：列出所有已部署的用户及其端口（方便您发给同事）。
    - `bash scripts/deploy-user.sh zhangsan down`：停止某人的服务。

## 3. 容量与扩容（保持原理解）
- **容量**：默认共享服务器磁盘。
- **扩容**：服务器加硬盘 -> 搬运 `users/` 下的对应文件夹 -> 重启。
