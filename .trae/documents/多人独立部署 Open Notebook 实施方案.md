# 多人独立部署 Open Notebook 实施方案

为了实现“每个人一个独立环境”的目标，我们将采用 **多目录 + 多端口** 的策略。

## 1. 目录结构规划
我们将为每位同事创建一个独立的部署目录，确保数据物理隔离。
*   `open-notebook-alice/` (同事 A)
*   `open-notebook-bob/` (同事 B)
*   ...

## 2. 端口规划与配置
由于服务器的 IP 是同一个，我们需要用不同的**端口号**来区分不同人的服务。
*   默认端口：`8502` (Web), `5055` (后端)
*   同事 A：`8602`, `5155`
*   同事 B：`8702`, `5255`
*   以此类推...

我们将修改 `docker-compose.yml` 中的 `ports` 映射，将左边的宿主机端口改为分配给该同事的专属端口。

## 3. 编写一键生成脚本 (Shell Script)
为了避免你每次手动复制文件夹和改代码，我将为你编写一个简单的脚本 `create_user.sh`。
*   **功能**：你只需要运行 `./create_user.shzhangsan`，它就会自动：
    1.  创建一个名为 `open-notebook-zhangsan` 的文件夹。
    2.  复制现有的配置文件。
    3.  自动分配并修改好端口号（避免手动改错）。
    4.  准备好启动命令。

## 4. 验证部署
我们将尝试生成一个测试用户的环境，并验证其能否正常启动且数据独立。
